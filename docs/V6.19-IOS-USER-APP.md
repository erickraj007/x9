# v6.19 — X9 user app for iPhone

Adds iOS to the existing X9 user app. Android, the server and the portal are unchanged.

## What changed

| Area | Change |
|---|---|
| Build | New workflow `.github/workflows/ios.yml` (GitHub macOS runner): unsigned `.ipa` + Simulator app without secrets; signed `.ipa` and TestFlight upload with the Apple secrets. `apks.yml` is untouched. |
| Xcode project | Generated by `flutter create --platforms=ios` in the build, then configured by `.github/scripts/patch_ios.py` (bundle id `in.donezo.x9.user`, iOS 15.5, permission texts, UPI app schemes, `x9://` deep link, push, signing). Committed: `ios/Runner/AppDelegate.swift`, `ios/Podfile`, the X9 app icon set. |
| UPI apps on iPhone | `lib/services/upi_apps_ios.dart`: picker of installed UPI apps (Google Pay, PhonePe, Paytm, BHIM, CRED, Amazon Pay, MobiKwik, Other). Hooked in one place, `openExternal()` in `lib/util/helpers.dart`, only when `Platform.isIOS` and the link is `upi:`. So wallet top-up, bill payment, payment links, VIP and Scan & Pay of a UPI QR all use it on iPhone. Android keeps its native list. |
| Push on iPhone | `lib/services/push.dart`: iOS settings for local notifications (foreground banners) and `platform: IOS` when registering the token (the server already accepts IOS). |
| Docs | `docs/IOS-BUILD.md` (Apple account, certificate, profile, secrets, TestFlight, App Store review notes). |

## Code diff (Dart, 3 files)

* `lib/util/helpers.dart`: `import 'dart:io' show Platform;`, `import '../services/upi_apps_ios.dart';`, and in
  `openExternal()`:
  `if (Platform.isIOS && url.toLowerCase().startsWith('upi:')) return openUpiOnIos(context, url, failMessage: failMessage);`
* `lib/services/push.dart`: `DarwinInitializationSettings` / `DarwinNotificationDetails` added next to the Android
  ones; token platform `Platform.isIOS ? 'IOS' : 'ANDROID'`.
* `lib/services/upi_apps_ios.dart`: new.

## Not tested here

There is no macOS / Xcode in this workspace, so the iOS build was not compiled here. The first GitHub run of
`Build X9 iOS app` is the compile test; the UPI app schemes must be checked on a real iPhone (TestFlight).

## Install

See `README.txt` in the fix pack, or copy the files listed above into the repository and push. Then
**Actions → Build X9 iOS app → Run workflow**. Signing and TestFlight: `docs/IOS-BUILD.md`.
